# 11 · 演示剧本（验收与录屏脚本）

> 每个剧本 = 验收标准 + 30-60 秒录屏分镜。录屏存 `docs/demos/`，简历/面试现场素材。

## S1 · 跨设备同会话（US-01/02 验收）

**前置**：M3 完成，workpc 浏览器 + 手机 PWA 已登录。

```
1. [workpc 浏览器] 打开 DoraHub → 新建会话"重构调研"
   发送："帮我调研 WebSocket 重连的几种策略，先列要点"
2. [录屏切手机] PWA 打开 → 会话列表点进"重构调研"
   → 看到正在流式输出的回答（逐字出现）
3. [手机] 直接追问："第 2 点展开讲讲" → 发送
4. [切回 workpc] 刷新/无需刷新 → 看到 phone 发的消息 + 新回答
```
**通过标准**：两边最终消息历史完全一致；步骤 2 中手机能看到实时流。

## S2 · 运行中 steer（US-03 验收）

```
1. [workpc] 发送长任务："通读 docs/ 下所有 md，输出一份索引文档"
   （agent 开始多轮 read 工具调用，工具卡片滚动）
2. [手机] 打开同一会话 → 打开 steer 开关 → 输入："跳过 design/ 子目录，太长了"
   → 发送（消息以 steer 样式插入显示）
3. 观察当前工具轮结束后，agent 的后续 read 不再碰 design/，
   最终输出说明"已按要求跳过 design/"
```
**通过标准**：steer 消息在当前轮后生效；最终产物符合 steer 内容。

## S3 · 权限拦截与手机放行（US-05 验收）

```
1. [配置] guard-rules.json 已含 bash 危险规则（如 rm -rf）
2. [workpc] 发送："帮我执行 rm -rf /tmp/dorahub-test-dir 清理测试目录"
3. 工具卡片变为"等待确认"（红边），同时 [手机] 震动 + 置顶确认卡
4. [手机] 点"允许" → workpc 侧工具继续执行完成
5. （重复一遍点"拒绝"的分支，验证 block 消息回到模型）
```
**通过标准**：拦截 → 推送 → 手机决策 → 执行/阻断，全链路 < 5 秒。

## S4 · 崩溃恢复（US-04 验收，简历 demo 之魂）

```
1. [手机] 发起会跑 5+ 轮工具的任务："逐个文件检查 src/ 里的 TODO 并汇总"
2. [workpc SSH] 任务跑到第 3 轮时：sudo systemctl kill -s SIGKILL dorahub
3. [手机] WS 断开提示（黄条）→ 几秒后自动重连（绿条）
4. hub systemd 拉起 → harness.resume() → 任务从断点继续
5. 最终汇总结果完整产出；对比 sqlite 里 transcript：被中断的工具调用
   标记 interrupted，安全调用（read）自动重跑完成
```
**通过标准**：全程无需人工干预；结果完整；中断痕迹可在 transcript 中指认（面试时展示数据库记录是高光时刻）。

## S5 · 手机遥控工作电脑执行（US-06 验收，M4）

```
1. [手机] 新建会话 → 目标机选 workpc → cwd 填 F:\work\repo
2. 发送："统计这个仓库里的 TODO 数量，列出最集中的 3 个文件"
3. 工具卡片显示 bash 执行 → （另一画面：workpc 屏幕上 exec-agent 日志
   显示真实子进程在本地跑）→ 结果返回
4. [手机] 追加："把 TODO 最多的文件里前 3 条贴出来" → read 卡片 → 结果
```
**通过标准**：工具确在 workpc 执行（路径/进程可指认）；全程手机操作。

## 录屏技巧

- 手机端用系统录屏；workpc 用 OBS；S1 这种跨设备剧本，两路录屏后期并排（简单的 ffmpeg 拼接即可，`ffmpeg -i a.mp4 -i b.mp4 -filter_complex hstack out.mp4`）
- 每个剧本开头加 1 秒黑屏标题帧（剧名 + 里程碑号）
- S4 剧本务必把 SSH 窗口（kill 命令）和手机画面同框，冲击力最强
